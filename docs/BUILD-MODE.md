# Construir y amueblar en Auralis Atlas

El catálogo inferior reúne **Construir**, **Amueblar** y **Acabados**. Puedes recogerlo con la flecha para ampliar la vista. El panel lateral conserva las plantas, las luces, las referencias y el lote. Selecciona un elemento y pulsa **Propiedades** para editar sus medidas exactas.

## Colocar objetos

1. Abre **Amueblar**, busca una pieza o filtra su familia.
2. Muévela sobre el suelo del plano 2D o la vista 3D. La vista previa verde indica que cabe; la roja explica qué obstáculo encuentra.
3. Pulsa **R** para girar 90° o **, / .** para pasos de 45°. La barra inferior también tiene botones de giro.
4. Haz clic para colocarla. **Repetir** mantiene la pieza en la mano para colocar varias.

**Alt** permite colocar sin ajuste a la cuadrícula. **F5** alterna pasos de 1, 0,5, 0,25 y 0,1 metros. El selector superior permite otros pasos. **9 / 0** o **RePág / AvPág** suben o bajan la pieza 10 cm; el campo Altura admite un valor exacto en metros.

**Superponer** permite cruzar voluntariamente los volúmenes de muebles y paredes. Úsalo para composiciones que lo necesiten. El límite del lote se conserva. La comprobación usa volúmenes orientados, no el detalle de cada triángulo; una pieza con huecos puede necesitar esta opción. Las alfombras permiten objetos encima.

Pulsa **I** y toca un objeto para colocar otro con sus dimensiones, color, giro y altura. **Ctrl+D** copia el mueble o la habitación seleccionados a una vista previa que puedes colocar libremente. **Esc** termina la colocación.

## Habitaciones y paredes

En **Construir**, elige **Espacio libre** y arrastra desde una esquina hasta la opuesta. También puedes marcar ambas esquinas con dos clics. Las habitaciones rápidas ofrecen tamaños iniciales que puedes cambiar después en Propiedades.

Las habitaciones son rectangulares. Puedes moverlas en 3D; sus muebles, luces y paredes independientes interiores las acompañan. **Girar habitación 90°** conserva las dimensiones de sus muebles y transforma las puertas, ventanas y destinos de las luces. **Copiar** conserva su distribución y crea identificadores nuevos. Las habitaciones no pueden ocupar la misma superficie.

**Pared** permite arrastrar o marcar extremos y continuar una cadena. Mantén **Mayús** para trazar en ángulos de 45°. Pulsa **Esc** para terminar. Puertas y ventanas se colocan sobre el muro y se ajustan desde Propiedades.

Pulsa **K** o el icono de papelera para demoler con un clic. Al eliminar una pared de una habitación se conserva su suelo y mobiliario; las paredes restantes pasan a ser independientes. Una pared compartida completa se retira de ambos espacios. **Ctrl+Z** deshace la operación como un único paso.

## Acabados

Abre **Acabados**, elige un suelo y toca la superficie de la habitación. El cuentagotas también puede capturar el acabado de otro suelo. El material se conserva al mover o copiar la habitación.

## Guardado y compatibilidad

La biblioteca sigue siendo local. El formato v4 conserva las paredes demolidas y puede abrir proyectos v1, v2 y v3. Conserva una copia del archivo original si necesitas usar una versión antigua de Atlas: las versiones anteriores a esta revisión no admiten v4.

El autoguardado conserva los cambios que han terminado de persistirse en este dispositivo. Descarga un archivo editable para disponer de una copia fuera del navegador o teléfono. Un corte de energía puede perder las últimas acciones que todavía no habían terminado de guardarse.

El sistema toma como referencia la comodidad de los modos de construcción de simulación doméstica, con controles, geometría, catálogo e identidad propios. No usa modelos ni recursos de Los Sims.
